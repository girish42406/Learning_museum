# The Learning Museum

> *"Not just what I've built, but what I've learned along the way."*  
> Curated interactive 3D virtual museum by **Girish Prasad Sharma** (First-Year Student exploring Computer Science, Artificial Intelligence, and Quantitative Technologies).

---

## 🏛️ Features & Architecture

- **Interactive 3D Spatial Museum**: Built with **React 18**, **Three.js**, **React Three Fiber (v8)**, and **Drei (v9)**.
- **Themed Exhibition Wings**:
  1. **Entrance Hall**: Welcome rotunda introducing Girish's journey and learning philosophy.
  2. **Project Gallery**:
     - *MedSaathi* — AI Medicine Safety Checker (Python & Streamlit; includes prominent medical safety disclaimer).
     - *Infinite Loops* — Voice-Cloning & Telephone Scam Detection (Hacktoberfest/SIH, AASIST, RawNet2, Whisper, Groq LLM; GitHub repository link).
     - *Interactive Personal Portfolio* — 3D virtual museum built with Antigravity IDE.
  3. **Achievement Hall**:
     - WorldQuant BRAIN Bronze Certification.
     - WorldQuant BRAIN Silver Certification.
     - WorldQuant BRAIN Challenge Gold Level Certificate.
     - Official placeholder frames ready for certificate scans.
  4. **Learning Lab**:
     - Active competencies: Python, C++, Competitive Programming, Git & GitHub, Linux & CLI, AI, Backend Development, Quantitative Research (framed honestly as learning areas).
  5. **Community Wing**:
     - Minds Club (Member).
     - E-Cell, Newton School of Technology (Member).
  6. **Future Wing**:
     - 6 concrete milestones spanning startup building, quant research, CP, C++, backend architectures, and practical AI.
- **AI Museum Guide**: Local rule-based assistant providing instant topic answers, direct teleport shortcuts, and modular architecture ready for future Gemini/LLM API integration.
- **2D Accessible Fallback**: Automatic WebGL detection and manual toggle between 3D Spatial View and a clean, responsive 2D Exhibition View.

## 🚀 Running the Project Locally

### 1. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```

### 3. Preview Production Build
```bash
npm run preview
```
